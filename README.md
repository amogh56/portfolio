# Amogh Yalameli - Developer Portfolio 🚀

Welcome to my personal developer portfolio repository! This project highlights my work, skills, and experience as a Full-Stack and AI & ML Engineer.

## ✨ Features

- **Interactive 3D Avatar**: Custom 3D typing character interacting with user scrolling and movement.
- **Glassmorphic Bento Grid**: Responsive modern grid representation of technical stack skills.
- **Horizontal Scroll Gallery**: Showcasing projects (EventVault, HealthHub, Moodsong) in a smooth slide structure.
- **Performance Optimized**: Streamlined bundles, statically loaded critical modules, and low-latency interaction listeners.

## ⚙️ Tech Stack

- **Frontend**: React, TypeScript, GSAP (ScrollTrigger & ScrollSmoother), Three.js / React Three Fiber, Vanilla CSS
- **Backend & Tools**: Node.js, Express, MySQL, MongoDB, Google Cloud Platform, Git
